# ASVspoof 2019 Logical Access preflight

The planned primary corpus is the official ASVspoof 2019 Logical Access release:

- DOI: https://doi.org/10.7488/ds/2555
- Public record: https://zenodo.org/records/6906306
- Archive: LA.zip
- Published archive size: 7.6 GB
- Published MD5: 30c98f11d8b2bc21f2c257bfd78bb5c5
- License: Open Data Commons Attribution License (ODC-By)

The release contains official train, development, and evaluation partitions with
speaker-disjoint source speech. Train and development contain known spoofing attacks;
evaluation additionally contains attacks generated by different algorithms or
conditions. The project will preserve these partitions exactly.

## Intended local placement

    ~/audio/cache/downloads/LA.zip
    ~/audio/data/asvspoof/2019-la/raw/
    ~/audio/data/asvspoof/2019-la/protocols/
    ~/audio/data/asvspoof/2019-la/manifests/

The archive will be checksum-verified before extraction. Dataset audio, original
protocols, and full manifests stay outside Git. Only attribution, preparation code,
schema documentation, aggregate counts, and small audit tables belong in the code
repository.

## Leakage policy

- Train only on the official training partition.
- Select models, thresholds, and corruption policies only with development data.
- Keep evaluation labels unavailable to training and selection code.
- Run the official evaluation split only after the development protocol is frozen.
- Retain speaker ID and attack ID in manifests for overlap and subgroup audits.

No dataset was downloaded during Phase 1.
